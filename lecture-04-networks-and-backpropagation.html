Chapter 4 · CS231N, Spring 2025

Neural representations and the backward computation

A nonlinear network changes the representation of an image. Backpropagation computes how each part of that computation influences a scalar objective, reusing local derivative rules instead of expanding one enormous formula.

Based on the complete Lecture 4 recording, its official slide text, and primary differentiation references. The inspection examples, matrix fixtures, memory calculation, and exercises are original. Mathematical gradients are distinguished from biological analogies and optimizer updates.

1. More layers matter only when the computation changes 9:53

Our inspection model must separate acceptable parts, scratches, and gouges. A single affine scoring rule divides its input space using hyperplanes. If acceptable examples surround damaged examples, or one defect has several distinct appearances, that family may be too restrictive. Collecting additional examples does not remove a representational limitation; we need a different map from inputs to scores.

For one image, let \(x\in\mathbb R^d\) be its feature vector, \(h\) the number of hidden units, and \(C\) the number of output classes. Using a column-vector convention, define a two-layer network by

\[ a=W_1x+b_1,\qquad z=\phi(a),\qquad s=W_2z+b_2, \]

where \(W_1\in\mathbb R^{h\times d}\), \(b_1\in\mathbb R^h\), \(W_2\in\mathbb R^{C\times h}\), and \(b_2\in\mathbb R^C\). The activation function \(\phi\) acts elementwise here. The hidden preactivation is \(a\), the hidden representation is \(z\), and the class-score vector is \(s\). “Two layers” conventionally counts the two learned affine transformations; the input is not counted as a learned layer.

If \(\phi\) is the identity function, then \(s=(W_2W_1)x+(W_2b_1+b_2)\), another affine map. Depth without a nonlinear operation does not escape the original family. With a nonlinear activation, the first layer can expose distinctions that the second separates. The lecture illustrates this with a nonlinear coordinate transformation that makes previously inseparable classes linearly separable.

An original one-dimensional example makes the mechanism explicit. Suppose a scalar measurement \(r\) describes deviation from a nominal surface profile, and a part is unacceptable when \(|r|>1\). Define two hidden features \(z_1=\max(0,r)\) and \(z_2=\max(0,-r)\). Their sum equals \(|r|\), so a final score \(s=z_1+z_2-1\) distinguishes the two extreme regions from the acceptable middle. No single threshold of the form \(ar+b>0\) can represent both tails and exclude the interval between them.

This is a small constructive expressivity result. It does not show that training from arbitrary initialization will discover these features, or that an image-based defect detector should use this particular scalar. It separates what a model can express from what an optimization procedure learns. The lecture’s “templates” interpretation is similarly a useful intuition: hidden units can supply reusable features to several classes, but each unit need not correspond to a recognizable object part.

2. Activation functions control values and derivatives 18:36

The rectified linear unit, ReLU, is \(\phi(a)=\max(0,a)\). For positive \(a\), its derivative is one; for negative \(a\), zero. It is not differentiable at zero, where software uses a specified convention, often zero. A ReLU network is piecewise affine: within a region where the signs of all preactivations remain fixed, the gates are fixed and the resulting map is affine. Crossing a gate boundary changes that local map.

A unit that stays negative on all relevant examples passes zero values and zero derivatives through that activation. This can prevent its incoming weights from receiving a learning signal through those examples, a phenomenon often called a dead ReLU. A leaky ReLU uses a small positive slope on the negative side, allowing a signal there. It changes the model rather than proving that optimization will always succeed.

The sigmoid \(\sigma(a)=1/(1+e^{-a})\) maps a real number to \((0,1)\). Differentiating gives \(\sigma'(a)=\sigma(a)(1-\sigma(a))\). Its derivative is at most one-quarter and approaches zero in both tails. The hyperbolic tangent maps to \((-1,1)\) and has derivative \(1-\tanh^2(a)\), which also becomes small in its saturated tails. Repeated small derivative factors can attenuate backward signals, although weight matrices and the full composition also matter.

The lecture surveys alternatives including exponential linear units, Gaussian error linear units, and sigmoid-weighted linear units. An ELU uses a linear positive branch and an exponential negative branch, allowing negative outputs with a different derivative profile. The GELU paper defines the activation \(a\Phi(a)\), where \(\Phi\) is the standard-normal cumulative distribution function. The SiLU paper defines \(a\sigma(a)\). These multiply the input by a smooth value-dependent factor instead of ReLU’s hard sign gate.

Choice of activation affects both what the model represents and how gradients propagate. Smoothness, output centering, saturation, computational cost, and architectural precedent are useful considerations, but no single property identifies a universally best function. Sigmoid and tanh remain appropriate for specific uses, including gates and bounded outputs. A statement that they can saturate is not a blanket prohibition.

Width and regularization must also be evaluated together. The lecture favors enough capacity to fit meaningful structure, then tuning regularization rather than relying solely on a tiny network to suppress overfitting. This is a development heuristic, not a rule that model size should never be varied. Compute, latency, data volume, and target complexity all constrain the choice. Neither greater width nor a positive regularization coefficient guarantees generalization.

Finally, the word “neuron” is a loose inspiration. A numerical affine transformation followed by a scalar activation omits much of the physiology, dynamics, and connectivity of biological cells. The lecture explicitly warns against equating the two. The mathematical value of the model comes from its specified computation and evidence of behavior, not the biological name.

3. A computational graph exposes reusable local structure 38:53

Let \(L\) be a scalar training objective. It might combine categorical negative log-likelihood with a parameter penalty, or use a different task loss. The lecture revisits hinge loss to emphasize that turning scores into probabilities is not the only option. Changing the final loss should not require deriving every preceding layer again from scratch.

A computational graph records dependencies among operations. In the forward pass, inputs and parameters produce intermediate values and eventually \(L\). In the backward pass, derivative information follows those dependencies in reverse. Each operation needs a local derivative rule and whatever forward values that rule requires.

Consider a tiny inspection calibration module with scalar gain \(a\), measured feature \(b\), desired response \(c\), and nonnegative penalty strength \(\lambda\). Define

\[ r=ab,\qquad e=r-c,\qquad L_{\mathrm{data}}=\frac12e^2,\qquad L_{\mathrm{reg}}=\frac\lambda2a^2,\qquad L=L_{\mathrm{data}}+L_{\mathrm{reg}}. \]

The gain \(a\) affects the loss through two paths: the prediction error and its own penalty. This simple branch captures an issue that occurs throughout modern networks: shared values can influence the result more than once.

A graph describes the computation we chose. Replacing a chain of primitive operations by a fused operation can preserve the function while changing storage and numerical behavior. For example, sigmoid can be represented as negation, exponentiation, addition, and reciprocal, or as one operation with its known derivative. Either representation must produce the same mathematical chain rule under equivalent assumptions.

4. Backpropagation is the chain rule with accumulation 43:41

For any scalar intermediate \(v\), write its adjoint as \(\overline v=\partial L/\partial v\). This is the sensitivity of the final loss to \(v\), including all paths through the graph. Seed the backward calculation with \(\overline L=1\), because a scalar changes one-for-one with itself.

At an operation \(z=f(u,v)\), the incoming or upstream gradient is \(\overline z\). The local derivatives are \(\partial z/\partial u\) and \(\partial z/\partial v\). Their products contribute to the downstream adjoints: \(\overline u\mathrel{+}=\overline z\,\partial z/\partial u\) and \(\overline v\mathrel{+}=\overline z\,\partial z/\partial v\). The addition symbol is essential whenever a value has more than one use.

For our inspection graph, the sum sends gradient one to each loss branch. Squaring gives \(\overline e=e\). Subtraction gives \(\overline r=e\) and \(\overline c=-e\). Multiplication then contributes \(eb\) to \(\overline a\) and \(ea\) to \(\overline b\). The regularization branch contributes \(\lambda a\) to \(\overline a\). Therefore

\[ \frac{\partial L}{\partial a}=eb+\lambda a,\qquad \frac{\partial L}{\partial b}=ea,\qquad \frac{\partial L}{\partial c}=-e. \]

With \(a=2,b=3,c=5,\lambda=0.1\), we obtain \(r=6\), \(e=1\), and \(L=0.5+0.2=0.7\). The derivatives are 3.2, 2, and \(-1\). Forgetting the penalty branch would report 3 instead of 3.2 for the gain derivative. Overwriting rather than accumulating contributions can thus produce a plausible-looking but incorrect answer.

The common gate rules now have a precise interpretation. Addition copies an incoming scalar derivative to each input. Multiplication scales it by the other operand. A copied value accumulates contributions from all consumers. A max operation with a unique winner routes the derivative to that winning input and gives zero to the other. At ties, max is nondifferentiable; the implementation chooses a convention or subgradient rather than applying the unique-winner rule without qualification.

A sigmoid example distinguishes the derivative of a prediction from the derivative of its loss. In this local scalar example, let an input measurement be \(x=2\), weight \(w=0.5\), and bias \(b=-1\). The preactivation is \(a=wx+b=0\), and the predicted probability is \(p=\sigma(a)=0.5\). The derivative of the probability with respect to its preactivation is \(p(1-p)=0.25\). That number alone is not yet the training signal.

If the binary target is one and the loss is \(L=-\log p\), then the upstream derivative with respect to \(p\) is \(-1/p=-2\). Multiplying by the local sigmoid derivative gives \(\partial L/\partial a=-0.5\). The earlier affine operation then gives \(\partial L/\partial w=-0.5x=-1\) and \(\partial L/\partial b=-0.5\). A small negative-gradient update raises both parameters here, increasing the predicted probability of the correct binary outcome. Treating 0.25 as the loss gradient would even give the wrong update direction.

The same prediction can be computed by expanding sigmoid into elementary operations or by using a fused sigmoid gate. Its derivative is unchanged in exact arithmetic because both represent the same function. A fused loss implementation can additionally avoid unstable intermediates, such as computing a tiny probability and then taking its logarithm. Modularity therefore has two purposes: it avoids repeating the chain-rule derivation, and it allows a carefully implemented operation to improve numerical behavior. A fused implementation must still correspond to the intended objective and derivative convention.

Why reverse order? To compute a node’s adjoint, all later operations that consume it must have contributed. Processing the graph in reverse topological order ensures that dependency. The data themselves flow forward; sensitivities of the final loss flow backward. Neither direction is an optimizer. Only after obtaining parameter gradients does an update rule such as SGD or Adam decide how to change parameters.

Lecture anchor: local and upstream derivatives. The automatic-differentiation survey by Baydin and colleagues places this reverse computation in the broader family of differentiation techniques.

5. Vector derivatives are products, not collections we must store 64:47

Let \(x\in\mathbb R^d\) and \(z=f(x)\in\mathbb R^m\). Define the Jacobian with output index first: \(J_{ij}=\partial z_i/\partial x_j\), so \(J\) has shape \(m\times d\). This convention must be stated because some presentations transpose the displayed derivative layout. Let \(\overline z=\nabla_z L\in\mathbb R^m\) be a column gradient. Then

\[ \overline x=J^\mathsf T\overline z,\qquad \overline x_j=\sum_{i=1}^{m} \overline z_i\frac{\partial z_i}{\partial x_j}. \]

Each input coordinate receives the sum of its effects through all output coordinates. The result has shape \(d\), the same as \(x\). For a matrix or higher-order tensor variable, its gradient with respect to a scalar loss has the same shape as that variable when we arrange the partial derivatives by its entries.

This is often called a vector–Jacobian product, using a row-vector convention, or a Jacobian-transpose–vector product using the column convention above. The mathematical information is the same. Backpropagation needs that product, not the complete Jacobian as an intermediate object.

For elementwise ReLU away from zero, the Jacobian is diagonal, with ones for positive preactivations and zeros for negative ones. Therefore \(\overline x=\overline z\odot\mathbf1[x>0]\), where \(\odot\) denotes elementwise multiplication. For \(x=(2,-1,0.5)\) and \(\overline z=(3,4,-2)\), the result is \((3,0,-2)\). Building a dense three-by-three matrix is unnecessary even in this small case; for millions of entries it would be disastrous.

Implicit derivative products also reveal a memory tradeoff. A multiply operation needs its operands during the backward pass. ReLU needs enough information to recover the sign mask. Sigmoid can reuse its forward output for \(\sigma(1-\sigma)\). Saving these values speeds backward computation but consumes memory. Recomputing selected intermediates can trade additional work for less storage, provided the recomputation matches the original operation.

The official PyTorch autograd documentation explains graph construction, saved tensors, and handling of nondifferentiable operations. Those implementation details clarify a boundary: automatic differentiation differentiates the executed computational program according to its operation rules. It is neither finite differencing nor a symbolic expansion of a closed-form network expression. It is also not evidence that the program computes the intended scientific objective.

6. Derive matrix multiplication backward one index at a time 71:08

Switch now to a row-batch convention. Let \(X\in\mathbb R^{N\times d}\) contain \(N\) examples, \(W\in\mathbb R^{d\times m}\) be a weight matrix, and \(Y=XW\in\mathbb R^{N\times m}\). A scalar objective supplies upstream gradient \(G=\partial L/\partial Y\) with shape \(N\times m\). The forward entries satisfy \(Y_{nk}=\sum_{j=1}^dX_{nj}W_{jk}\).

Changing \(X_{nj}\) affects every output in row \(n\), with local derivative \(W_{jk}\) for output \(k\). It does not affect other rows. Accumulating those paths gives

\[ \frac{\partial L}{\partial X_{nj}} =\sum_{k=1}^m G_{nk}W_{jk}, \qquad \frac{\partial L}{\partial X}=GW^\mathsf T. \]

Changing \(W_{jk}\) affects output column \(k\) in every example, because the weights are shared across the batch. Its contributions therefore sum over examples:

\[ \frac{\partial L}{\partial W_{jk}} =\sum_{n=1}^N X_{nj}G_{nk}, \qquad \frac{\partial L}{\partial W}=X^\mathsf TG. \]

The transpose placements follow from dependencies, not a memorized “swap” slogan. Shape checks are useful—\(GW^\mathsf T\) is \(N\times d\), and \(X^\mathsf TG\) is \(d\times m\)—but compatible shapes alone do not prove a derivative is correct. A wrong formula can have the correct shape.

For a concrete fixture, take \(X=\begin{bmatrix}1&2\\-1&1\end{bmatrix}\), \(W=\begin{bmatrix}2&0\\1&-1\end{bmatrix}\), and \(G=\begin{bmatrix}1&3\\-2&4\end{bmatrix}\). Forward multiplication gives \(Y=\begin{bmatrix}4&-2\\-1&-1\end{bmatrix}\). The gradients are \(GW^\mathsf T=\begin{bmatrix}2&-2\\-4&-6\end{bmatrix}\) and \(X^\mathsf TG=\begin{bmatrix}3&-1\\0&10\end{bmatrix}\). We can verify these by defining the scalar objective \(L=\sum_{n,k}G_{nk}Y_{nk}\) with fixed \(G\) and applying finite differences.

The lecture’s memory warning becomes sharper when calculated separately for each input. If \(N=64\) and \(d=m=4096\), then both \(X\) and \(Y\) have \(2^{18}\) entries. A dense Jacobian from \(X\) to \(Y\) has \(2^{36}\) entries and takes \(2^{38}\) bytes in float32: 256 GiB. But \(W\) has \(2^{24}\) entries, so a dense Jacobian from \(W\) to \(Y\) takes \(2^{44}\) bytes: 16 TiB. These are dense-storage counts, including zeros, not the memory required by the implicit products.

The matrix formulas avoid those objects entirely. The official linear-backpropagation handout supplies a complementary derivation. The computational advantage comes from exploiting the structure of the operation, which is precisely what a reusable backward rule encodes.

7. Assemble the whole two-layer backward pass 26:28

In the row-batch convention, use \(W_1\in\mathbb R^{d\times h}\), \(W_2\in\mathbb R^{h\times C}\), and bias row vectors \(b_1,b_2\). These weight orientations are transposes of the single-column convention at the start. Define \(A=XW_1+b_1\), \(H=\phi(A)\), and \(S=HW_2+b_2\), where broadcasting adds a bias to each row. Capital \(H\) is the matrix of hidden activations, while lowercase \(h\) remains the hidden width.

Let \(P_{nc}\) be the softmax probability of class \(c\) for example \(n\), and \(Q_{nc}\) its one-hot target. For mean categorical negative log-likelihood, the score gradient is \(G_S=(P-Q)/N\). The division by \(N\) belongs to the mean objective; it should not be applied again later in the chain.

Starting with this matrix, apply the local rules:

\[ G_{W_2}=H^\mathsf TG_S,\quad G_H=G_SW_2^\mathsf T,\quad G_A=G_H\odot\phi'(A),\quad G_{W_1}=X^\mathsf TG_A. \]

The bias gradients are row sums: \(G_{b_2}=\sum_n(G_S)_{n,:}\) and \(G_{b_1}=\sum_n(G_A)_{n,:}\). Each bias was copied across examples in the forward pass, so backward accumulation reverses that broadcasting. If the objective adds \(\frac\lambda2(\|W_1\|_F^2+\|W_2\|_F^2)\), add \(\lambda W_1\) and \(\lambda W_2\) to the two weight gradients. The Frobenius norm squared, \(\|W\|_F^2\), is the sum of squared matrix entries. Biases are unpenalized in this stated objective.

For ReLU, use a positive-preactivation mask away from its corner. For tanh, use \(1-H^{\odot2}\), reusing the forward activation. Either backward pass has the same surrounding matrix structure. Replacing the final data loss changes its seed gradient \(G_S\); preceding local rules stay valid for the new upstream signal. This modularity is the practical point of computational graphs.

Parameter sharing requires the same discipline beyond this simple network. If two images or two time steps use the same weights, their derivative contributions add to one parameter gradient. Accidentally creating separate copies changes the model. Accidentally overwriting one contribution preserves the model’s forward computation but corrupts its training signal.

8. Check derivatives before trusting a training curve

The following checks are original, small, and deterministic. They verify the scalar branch example and the matrix rules, then compare the laboratory’s two-layer tanh derivatives to central finite differences. Tanh avoids ReLU corners in this diagnostic; it is a deliberate smooth test case rather than a claim that tanh is best for image classification. The lab function omits biases, as its documented contract states.

import numpy as np
from numerical_lab import central_gradient, two_layer_loss_grad

point = np.array([2., 3., 5.])
def branch_loss(values):
    a, b, c = values
    return 0.5 * (a * b - c)**2 + 0.05 * a * a
assert abs(branch_loss(point) - 0.7) < 1e-12
assert np.allclose(central_gradient(branch_loss, point),
                   [3.2, 2., -1.], atol=1e-8)

X = np.array([[1., 2.], [-1., 1.]])
W = np.array([[2., 0.], [1., -1.]])
G = np.array([[1., 3.], [-2., 4.]])
assert np.array_equal(X @ W, [[4., -2.], [-1., -1.]])
assert np.array_equal(G @ W.T, [[2., -2.], [-4., -6.]])
assert np.array_equal(X.T @ G, [[3., -1.], [0., 10.]])
assert np.allclose(
    central_gradient(lambda weights: np.sum(G * (X @ weights)), W),
    X.T @ G, atol=1e-8)

first = np.array([[0.2, -0.3, 0.4], [0.5, 0.1, -0.2]])
second = np.array([[0.3, -0.5], [0.6, 0.2], [-0.1, 0.4]])
labels = np.array([0, 1])
_, dfirst, dsecond = two_layer_loss_grad(X, first, second, labels)
check_first = central_gradient(
    lambda weights: two_layer_loss_grad(X, weights, second, labels)[0],
    first)
check_second = central_gradient(
    lambda weights: two_layer_loss_grad(X, first, weights, labels)[0],
    second)
assert np.max(np.abs(dfirst - check_first)) < 1e-8
assert np.max(np.abs(dsecond - check_second)) < 1e-8

assert (64 * 4096)**2 * 4 == 256 * 2**30
assert (4096 * 4096) * (64 * 4096) * 4 == 16 * 2**40

A useful debugging sequence starts with a scalar objective, checks shapes, verifies one operation, then verifies the composition. Compare derivatives at several ordinary values, avoiding undefined points unless the convention itself is under test. If a finite-difference discrepancy persists across reasonable step sizes, inspect signs, reductions, shared paths, and cached values before changing the optimizer.

Passing these checks means the derivatives agree with the implemented objective at the tested points. A model can still optimize the wrong target, leak validation data, or fail under deployment shift. Derivative correctness is necessary for the intended gradient-based training procedure, but it is not a complete model evaluation.

9. Exercises with complete solutions

Exercise 1 · Build a nonlinear decision from simple gates

Using ReLU, express a score that is positive when \(r<-2\) or \(r>2\), and nonpositive for \(-2\leq r\leq2\). Explain why one affine threshold cannot do this.

Use \(s(r)=\max(0,r)+\max(0,-r)-2=|r|-2\). It is positive in either tail, zero at the two endpoints, and negative in the interior. A nonconstant affine scalar score changes sign at most once, whereas this target requires two boundary crossings. Two hidden ReLU features followed by an affine output provide the needed representation. The construction establishes existence, not successful recovery by any particular training run.

Exercise 2 · A shared value receives two gradients

For \(L=(w-2)^2+(2w+1)^2\), calculate the derivative by treating the two squared expressions as graph branches. Evaluate it at \(w=1\).

The first branch contributes \(2(w-2)\). The second contributes \(2(2w+1)\cdot2\), where the final factor is the derivative of its inner affine expression. Their sum is \(10w\), since the constants cancel. At \(w=1\), the derivative is 10. Keeping only one branch would give \(-2\) or 12, both wrong. The derivative can also be checked by expanding \(L=5w^2+5\), confirming the accumulation rule.

Exercise 3 · Explain a zero backward signal

A ReLU receives preactivation \(-0.7\) and upstream derivative 9. What is its downstream derivative? Would making the upstream derivative 900 change it? What would a negative-side slope of 0.02 do?

ReLU’s local derivative is zero at this negative input, so the downstream derivative is zero for either upstream value. A leaky ReLU with slope 0.02 gives downstream derivatives \(9(0.02)=0.18\) and \(900(0.02)=18\). The gate determines whether and how sensitivity flows. At zero the ordinary ReLU derivative is undefined, so a separate convention is required. A large upstream signal cannot compensate for an exactly zero local multiplier at a fixed negative preactivation.

Exercise 4 · Reverse broadcasting

A bias vector \(b\in\mathbb R^3\) is added to both rows of a two-example score matrix. Upstream derivatives are \((1,2,-1)\) and \((3,-2,4)\). What is the bias gradient, and why is it a sum rather than a mean?

The gradient is \((4,0,3)\). Each bias coordinate affects the corresponding score in both examples with derivative one, so the two paths add. If the scalar loss is a mean, its upstream derivatives should already include the mean’s scaling. Introducing another average here would incorrectly divide by two again. Broadcasting copies values forward and sums sensitivities backward.

Exercise 5 · Check Jacobian orientation and storage

A function maps a five-dimensional vector to a two-dimensional vector. Under the chapter’s output-by-input convention, what are the Jacobian and upstream-gradient shapes? How is the downstream gradient formed? Why might a framework never store the Jacobian?

The Jacobian is \(2\times5\), and the upstream column gradient is length two. Multiplying \(J^\mathsf T\), of shape \(5\times2\), by that gradient produces length five. The framework can implement this product directly from the operation’s structure, avoiding storage and multiplication of irrelevant entries. A differently oriented displayed Jacobian can be correct if the multiplication convention changes consistently; mixing conventions is the error.

Exercise 6 · Distinguish a derivative bug from a scientific error

A model passes finite-difference tests and reduces training loss, but fails on a new production line. Give two possible explanations consistent with correct backpropagation, and one additional check aimed specifically at implementation.

The training examples may encode a lighting shortcut absent from the new line, or the labels may represent a cosmetic criterion different from the intended mechanical defect criterion. Neither contradicts correct differentiation. Another possibility is a distribution shift in the new camera. An implementation-focused check is to verify shared-weight and bias gradients on a tiny batch with known dependencies, including accumulation and mean-loss scaling. Such a check can find a bug, but it cannot resolve whether the dataset represents the deployment task.

10. The backward pass is a reusable calculation

The lecture’s central result is that a complicated network can be differentiated by composing simple local rules. We added explicit shape conventions, branch accumulation, a full matrix derivation, and separate dense-Jacobian memory counts. Those details turn a verbal description of “sending error backward” into a checkable algorithm.

The worked examples establish derivative identities and test their implementations. They do not claim that artificial neurons reproduce biological learning or that a correct backward pass guarantees a useful model. Convolutional networks, introduced next, change the forward structure and its parameter sharing. The same chain rule will handle their backward computation.
