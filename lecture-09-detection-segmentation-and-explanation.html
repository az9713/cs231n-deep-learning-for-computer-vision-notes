Chapter 9 · CS231N, Spring 2025

Dense prediction, object sets, and visual explanations

Classification asks what is present. Segmentation and detection ask where it is and which instance it belongs to. Explanation asks a different question: which parts of the computation support a particular prediction?

This chapter follows the full Lecture 9 transcript and official slides. The transpose-convolution proof, matching example, overlap calculations, and diagnostic fixtures are original. Primary papers resolve several informal architectural descriptions in the lecture.

1. Let the output contract determine the model 15:49

Our inspection system can already classify a photograph as acceptable or defective. A factory operator now needs more: the location of each defective part, the outline of each scratch, and evidence for the decision. Those requirements create different mathematical output spaces. Treating them as interchangeable leads to the wrong labels, losses, and evaluation.

Image classification returns class scores for the whole image. Semantic segmentation returns one category per pixel, without distinguishing two objects of the same category. Object detection returns a variable-size set of labeled bounding boxes. Instance segmentation returns a separate mask for each detected object. A defect heatmap derived from a classifier is not automatically any of these supervised outputs.

If two adjacent parts have the same semantic category, their pixels can receive the same label even when the system must pick them up separately. Instance identity supplies the additional partition. Likewise, a box localizes an object only coarsely: it includes background and does not describe an irregular boundary. The inspection requirement should decide whether that approximation is adequate.

The lecture begins with a transformer recap: patch projection, position embeddings, a learned classification token or pooled patch outputs, pre-normalization, RMSNorm, gated feed-forward layers, and mixtures of experts. Chapter 8 derives those mechanisms. Their role here is to supply representations for new output heads. A learned classification token starts as an image-independent parameter but becomes image-dependent through attention; it is neither a class probability vector at initialization nor merely a scalar bias. Its final representation still needs a prediction head.

Architectural success is task-dependent. Neither attention nor a newer publication date establishes universal superiority. Detection remains a substantive task even when a library exposes it through one function call. The function hides training, coordinate conventions, confidence thresholds, and failure modes; it does not remove them.

2. Predict all pixels with shared computation 17:47

A single RGB pixel rarely contains enough context to distinguish a scratch from a shadow. One solution classifies a patch around every pixel. But neighboring patches overlap heavily, so separate network evaluations repeat much of the same computation. Fully convolutional prediction computes shared feature maps once, then produces spatial class scores.

For one image, use logits \(Z\in\mathbb R^{H\times W\times C}\), where \(H,W\) are output height and width and \(C\) is the number of categories. The class distribution at location \((i,j)\) is \(p_{ijc}=\exp(Z_{ijc})/\sum_r\exp(Z_{ijr})\). Given a valid-label set \(\Omega\) and targets \(y_{ij}\), a mean pixel loss is

\[ L_{\mathrm{seg}}=-\frac{1}{|\Omega|}\sum_{(i,j)\in\Omega}\log p_{ij,y_{ij}}. \]

The softmax normalization is over categories, not spatial positions. Its logit gradient is \((p_{ijc}-\mathbf1[c=y_{ij}])/|\Omega|\) for valid pixels and zero for ignored pixels. Ignored annotations must be removed from both the sum and its denominator. If no pixels are valid, the training code needs an explicit convention rather than division by zero.

Fully Convolutional Networks established an efficient path from classification features to dense output. Downsampling reduces spatial activation and arithmetic costs, while an upsampling path restores the desired output grid. Convolutional parameter count depends on kernel and channel dimensions, not directly on image area. Thus maintaining full resolution mainly increases computation and activation memory; it need not increase the number of learned kernel parameters.

The loss assumes annotations describe the intended task. Automated labeling tools may reduce manual effort, but their masks are still labels with possible errors. A model trained on pseudo-labels can inherit systematic boundary mistakes. For our inspection case, a strong image-level accuracy can coexist with unusable scratch boundaries, so pixel and instance evaluation must be designed separately.

Class imbalance illustrates the danger. If only 1% of pixels are defective, labeling every pixel as normal obtains 99% pixel accuracy and zero defect recall. Weighting classes, sampling informative regions, or adding overlap-based objectives changes the learning signal, but also changes the effective objective. Report the choices rather than treating them as free improvements.

3. Upsampling is not inversion 25:05

Nearest-neighbor upsampling copies each coarse value to a larger block. Zero insertion places coarse values at selected locations and fills the rest with zeros. Max unpooling uses stored argmax indices from a pooling layer to place values back at selected positions. None recovers information that downsampling discarded. Knowing which element was largest does not reveal the nonmaximal elements.

A transposed convolution is a learned linear map associated with the transpose of a convolution matrix. It is not ordinary convolution of a transposed image, and “transposed” does not mean “inverse.” Let a one-dimensional valid stride-two cross-correlation with kernel \((1,2,1)\) map five inputs to two outputs:

\[ C=\begin{bmatrix}1&2&1&0&0\\0&0&1&2&1\end{bmatrix},\qquad y=Cx. \]

The transpose maps \(u=(a,b)^\top\) to \(C^\top u=(a,2a,a+b,2b,b)^\top\). Each coarse input contributes a scaled copy of the kernel, and overlapping contributions add. For \(u=(2,3)\), the result is \((2,4,5,6,3)\). This is the precise linear version of the lecture’s overlap diagram.

The defining identity is \(\langle Cx,u\rangle=\langle x,C^\top u\rangle\). It explains why the transpose appears in backpropagation with respect to convolution inputs. But \(C^\top C\ne I\): \(C\) has at most rank two and cannot preserve all five input degrees of freedom. Upsampling reconstructs a plausible representation using learned regularities and other available features; it does not undo an arbitrary information-losing map.

For one spatial axis, a common transposed-convolution shape convention is

\[ n_{\mathrm{out}}=(n_{\mathrm{in}}-1)s-2p+d(k-1)+o+1, \]

where \(s\) is stride, \(p\) padding, \(d\) dilation, \(k\) kernel size, and \(o\) output padding. With input two, stride two, kernel three, dilation one, and padding one, the result is three when \(o=0\) and four when \(o=1\). The requested output size therefore needs a boundary convention. The official operator documentation clarifies that output padding resolves shape ambiguity; it is not simply a request to append learned content.

4. Preserve fine structure while learning context 28:57

A coarse representation sees a broad region efficiently but may lose precise boundaries. U-Net combines a contracting path with an expanding path and passes higher-resolution encoder features to the corresponding decoder stages. The original architecture concatenates these features, rather than simply adding them as a ResNet residual branch would.

Suppose a decoder tensor has shape \(H\times W\times D_d\), while a same-resolution encoder feature map has \(D_e\) channels. Concatenation yields \(H\times W\times(D_d+D_e)\). A following convolution learns how to combine local boundary evidence with broad semantic context. If spatial sizes differ, cropping, interpolation, or a padding convention must align them before concatenation. A U-shaped drawing is not a sufficient shape specification.

In inspection, a narrow scratch may disappear in the deepest representation but remain visible in earlier edge-sensitive features. The skip path gives the decoder access to that evidence. It does not guarantee sharp or correct masks: the network can still learn a shortcut, the input may be blurred, and the annotation may be inconsistent. Boundary quality should be measured at the scale relevant to the downstream action.

Mask overlap is one useful measure. For predicted positive-pixel set \(P\) and target set \(G\), intersection over union is \(\operatorname{IoU}(P,G)=|P\cap G|/|P\cup G|\). If both sets are empty, the raw expression is undefined and an evaluation protocol must specify how to handle it. Mean IoU also depends on which classes and empty cases enter the average. These choices matter when defects are rare.

5. Detection adds geometry and variable cardinality 32:48

For one object, a network can predict a class distribution and four box coordinates. A simple teaching objective is \(L=L_{\mathrm{class}}+\lambda\|b-\hat b\|_2^2\), with target \(b\), prediction \(\hat b\), and relative loss weight \(\lambda\). Coordinate units matter: pixel coordinates and normalized coordinates produce different loss scales. A box convention must identify whether \(x,y\) mean a center or a corner.

Multiple objects create a set prediction problem. The number of objects varies, and there is no natural ordering saying which object must occupy output slot one. A fixed bank of slots plus a “no object” label can represent variable cardinality, but supervision must still decide how predictions correspond to targets. Region-based methods, dense detectors, and matching-based transformers solve that assignment problem differently.

Use continuous corner coordinates \((x_1,y_1,x_2,y_2)\), with positive widths and heights. Intersection width is \(\max(0,\min(x_2,x'_2)-\max(x_1,x'_1))\), and similarly for height. Divide intersection area by the sum of individual areas minus intersection. Do not mix this convention with inclusive integer-pixel formulas that add one to widths.

For \(A=(0,0,2,2)\) and \(B=(0.5,0.5,2.5,2.5)\), the intersection is \(1.5^2=2.25\), union \(8-2.25=5.75\), and IoU \(9/23\approx0.3913\). Equal coordinate error can have very different relative impact on a tiny scratch box and a large part box. This motivates geometry-aware losses and size-specific evaluation.

A detector’s confidence score ranks hypotheses; a localization metric compares geometry. Neither is automatically the other. A high class score can accompany a badly placed box. Evaluating only cropped-object classification overlooks proposal recall and box quality, which may be the actual bottlenecks in the complete system.

6. Share the expensive image representation 36:30

Exhaustively evaluating windows at many positions, scales, and aspect ratios repeats work. R-CNN first proposes candidate regions, runs a CNN on each cropped region, and classifies and refines them. Its key computational limitation is the repeated feature extraction across overlapping crops.

Fast R-CNN extracts a shared image feature map before obtaining fixed-size region features. A region head predicts category and box refinement. Faster R-CNN adds a region proposal network that shares convolutional features. Two stages do not mean two entirely independent full-image backbone evaluations: feature sharing is the central optimization.

In a standard anchor-based RPN, reference boxes of predefined shapes are placed on a feature grid. Objectness scores and offsets are predicted from those references. This is more precise than imagining randomly initialized boxes wandering through the image. For grid height \(H_f\), width \(W_f\), and \(K\) anchors per position, there are \(KH_fW_f\) candidate boxes and four offset numbers per candidate.

A common center-size offset convention is \(t_x=(x-x_a)/w_a\), \(t_y=(y-y_a)/h_a\), \(t_w=\log(w/w_a)\), \(t_h=\log(h/h_a)\), where subscript \(a\) denotes the anchor. Decoding gives \(x=x_a+w_at_x\), \(w=w_a\exp(t_w)\), and analogous formulas for the other coordinates. Positive widths follow from the exponential, while the normalized displacement makes position changes relative to anchor scale.

For anchor center \((10,20)\), size \((4,8)\), and offsets \((0.5,-0.25,\log2,\log0.5)\), the decoded center is \((12,18)\) and size \((8,4)\). The resulting corners are \((8,16,16,20)\). Such hand checks catch swapped width/height axes and center/corner confusion before a training run obscures the problem.

7. Dense detection and duplicate suppression 43:57

Single-stage detectors directly predict a structured collection of boxes and class-related scores from image features. The lecture uses the original YOLO as its example. Its historical \(S\times S\times(5B+C)\) output combines \(B\) boxes and confidences per cell with \(C\) class probabilities shared within that cell. For \(S=7,B=2,C=20\), that is \(7\times7\times30=1470\) numbers, including 98 candidate boxes.

The original confidence target combines object presence with localization overlap; it is not simply a calibrated probability that an object exists. The original network also includes fully connected prediction layers. Later YOLO-family systems change many details, so neither the tensor layout nor the exact head architecture should be generalized to every version.

Multiple candidates can describe the same object. Greedy non-maximum suppression, or NMS, sorts candidates by score, keeps the best remaining box, and suppresses sufficiently overlapping lower-scored boxes, often separately for each class. Repeat until no candidates remain. The overlap threshold and whether comparison uses strict or non-strict inequality are part of the implementation contract.

Using our boxes \(A,B\) and a distant \(C=(4,4,5,5)\), suppose scores are \(0.9,0.8,0.7\). At a strict IoU threshold of 0.3, keeping \(A\) suppresses \(B\), and \(C\) survives. At threshold 0.5, all survive. If \(A\) and \(B\) correspond to two real adjacent objects, suppression loses a true detection. NMS is a heuristic about duplicate hypotheses, not proof that overlapping boxes represent one physical object.

Thresholds should be assessed on the complete operating requirement. A conveyor controller may prioritize missing no damaged parts, while a manual review queue may tolerate more false alarms. Speed also depends on preprocessing, image size, candidate count, and postprocessing, not only on the backbone’s nominal arithmetic.

8. Teach an unordered output through matching 49:00

DETR predicts a bank of object slots that interact through self-attention and read image features through cross-attention. Its learned object queries are parameters, not supplied image crops or a list of every possible box. Shared prediction heads turn the resulting slot representations into labels and coordinates. With \(N\) slots, at most \(N\) objects can be represented in that output bank.

The essential training ingredient is one-to-one assignment between predictions and targets. The original DETR paper uses bipartite matching and supervises unmatched slots as “no object.” The box objective combines L1 and generalized-IoU terms; the lecture’s generic L2 explanation should not be read as the exact DETR loss. Attention between slots alone does not guarantee unique predictions.

To see the assignment issue without a full detector, suppose two targets have matching costs against two predictions

\[ C=\begin{bmatrix}1&2\\1.1&100\end{bmatrix}. \]

Rows index targets and columns predictions. Choosing the lowest cost for the first target greedily gives column one, leaving cost 100 for the second: total 101. The global assignment sends target one to prediction two and target two to prediction one, for total 3.1. Independent per-target choices would instead reuse prediction one, violating the one-to-one constraint. The Hungarian algorithm solves the general assignment efficiently.

This fixture explains why supervision over sets needs more than a conventional ordered regression loss. Permuting target storage order should not change the intended task. Matching makes correspondence part of training, while a no-object category permits unused slots. A closed label vocabulary still cannot output an arbitrary new named category without changing the task representation or adding mechanisms such as language conditioning.

Increasing query count raises representational capacity for crowded scenes but does not guarantee recall or simply select the globally best objects. Optimization, object scale, occlusion, and the learned score function remain relevant. The chapter studies the architectural mechanism, rather than treating historical remarks about which detector is “deprecated” as evidence about present use.

9. Instance masks require spatial alignment 57:47

Mask R-CNN adds a mask branch to a region-based detector. Each region produces a small spatial mask that is mapped back to its image location. The original design predicts class-specific binary masks and trains the mask for the target class using per-pixel sigmoid binary cross-entropy; categories do not compete through a pixelwise softmax inside that mask branch. Classification remains a separate task.

The Mask R-CNN paper emphasizes RoIAlign, which avoids the coordinate rounding of RoI pooling and samples feature values with bilinear interpolation. A small spatial shift may barely affect category recognition but noticeably distort a mask boundary. The lecture’s additional slides make this alignment issue explicit.

On a unit cell with corner feature values \(f_{00},f_{10},f_{01},f_{11}\), a sample at horizontal fraction \(u\) and vertical fraction \(v\) is

\[ f(u,v)=(1-u)(1-v)f_{00}+u(1-v)f_{10}+(1-u)vf_{01}+uvf_{11}. \]

The weights sum to one and apply independently to every feature channel. With corner values \(0,2,4,6\) and \((u,v)=(0.25,0.5)\), the result is 2.5. Snapping to one neighboring cell would discard that subpixel distinction. Interpolation preserves a coordinate convention; it does not manufacture exact original-image detail beyond the feature map’s resolution.

10. Visualize sensitivity without confusing it with segmentation 61:52

First-layer filters can be displayed in RGB because their channel coordinates correspond directly to input colors. Deeper filters live in learned feature spaces, so simply painting three selected channels can be misleading. Looking at highly activating input patches or gradients offers other views, but each method answers a particular question.

For class score \(s_c(x)\), a gradient saliency map uses \(\nabla_xs_c(x)\). The local approximation is \(s_c(x+\delta)\approx s_c(x)+\nabla_xs_c(x)^\top\delta\). Holding model weights fixed and differentiating the input measures first-order sensitivity around that input. Training instead differentiates a loss with respect to parameters. The two derivatives have different domains and purposes.

The original saliency work uses class-score derivatives. One display convention takes the maximum absolute gradient over RGB channels at each pixel. Absolute values remove sign, so a bright region says “sensitive” without saying whether increasing a channel raises or lowers the score. Using probabilities instead of logits can introduce saturation and class competition effects.

A zero gradient does not prove a feature is irrelevant. For \(s(x)=x^2\), the derivative at zero is zero, but moving to one changes the score by one. Large perturbations need not obey a local linear approximation. Similarly, an attractive saliency image is not a ground-truth mask, a causal explanation, or evidence of medical validity. These distinctions are mathematical limitations of the measurement.

11. Derive CAM and its gradient-weighted extension 67:31

Suppose the last feature map is \(F\in\mathbb R^{H\times W\times K}\), followed by global average pooling and a linear classifier with weights \(w_{kc}\). Then

\[ s_c=b_c+\sum_k w_{kc}\frac{1}{HW}\sum_{i,j}F_{ijk} =b_c+\frac{1}{HW}\sum_{i,j}M_{cij},\qquad M_{cij}=\sum_k w_{kc}F_{ijk}. \]

This is CAM’s exact score decomposition for that architecture. The bias is spatially constant and is not represented in the map. Class activation mapping makes a useful connection between a classifier and coarse localization, but the decomposition depends on the pooling-plus-linear-head structure.

For two feature channels \(F_1=\begin{bmatrix}1&2\\3&4\end{bmatrix}\), \(F_2=\begin{bmatrix}4&3\\2&1\end{bmatrix}\), and class weights \((2,-1)\), CAM gives \(M=\begin{bmatrix}-2&1\\4&7\end{bmatrix}\). Its mean is 2.5, equal to the class score without bias. Negative regions contribute against that class under this linear decomposition; hiding them changes the interpretation.

Grad-CAM replaces classifier weights with averaged score gradients at a chosen spatial feature layer \(A\):

\[ \alpha_k^c=\frac{1}{HW}\sum_{i,j}\frac{\partial s_c}{\partial A_{ijk}}, \qquad G_{cij}=\operatorname{ReLU}\left(\sum_k\alpha_k^cA_{ijk}\right). \]

This applies beyond the exact CAM architecture, provided the chosen representation has a meaningful spatial layout. It averages gradients over space and keeps positive evidence, making it a coarse diagnostic rather than an exact decomposition in general. In the special CAM architecture above, gradients are \(w_{kc}/(HW)\), so Grad-CAM is \(\operatorname{ReLU}(M)/(HW)\): the same positive pattern up to scale.

Attention visualizations give another view of a transformer’s internal routing, but inherit the explanation caveats of Chapter 8. Guided backpropagation, shown in additional slides, alters the usual ReLU backward rule and should not be described as the ordinary gradient of the original network. Saliency sanity checks motivate testing whether explanations respond to learned parameters and labels, rather than trusting visual sharpness alone.

12. Verify geometry and explanation identities

The following independent fixtures check the transpose identity, its failure to invert, overlap conventions, NMS behavior, global matching, interpolation, and the CAM gradient relationship. They do not train a detector or validate a saliency method on real images.

import itertools
import numpy as np
from numerical_lab import box_iou, central_gradient

conv = np.array([[1, 2, 1, 0, 0], [0, 0, 1, 2, 1]], dtype=float)
x = np.array([1, -1, 2, 0, 3], dtype=float)
u = np.array([2, 3], dtype=float)
assert np.allclose(conv.T @ u, [2, 4, 5, 6, 3])
assert np.isclose((conv @ x) @ u, x @ (conv.T @ u))
assert not np.allclose(conv.T @ conv, np.eye(5))

boxes = np.array([[0, 0, 2, 2], [.5, .5, 2.5, 2.5], [4, 4, 5, 5]])
assert np.isclose(box_iou(boxes[0], boxes[1]), 9 / 23)
def nms(scores, threshold):
    order = sorted(range(len(scores)), key=lambda i: (-scores[i], i))
    keep = []
    while order:
        chosen = order.pop(0)
        keep.append(chosen)
        order = [i for i in order if box_iou(boxes[chosen], boxes[i]) <= threshold]
    return keep
assert nms([.9, .8, .7], .3) == [0, 2]
assert nms([.9, .8, .7], .5) == [0, 1, 2]

cost = np.array([[1, 2], [1.1, 100]])
assignments = list(itertools.permutations(range(2)))
totals = [sum(cost[i, p[i]] for i in range(2)) for p in assignments]
assert assignments[int(np.argmin(totals))] == (1, 0)
assert np.isclose(min(totals), 3.1)

u, v = .25, .5
value = (1-u)*(1-v)*0 + u*(1-v)*2 + (1-u)*v*4 + u*v*6
assert np.isclose(value, 2.5)
features = np.stack([[[1, 2], [3, 4]], [[4, 3], [2, 1]]], axis=-1)
weights = np.array([2., -1.])
cam = features @ weights
score = lambda z: float(z.mean(axis=(0, 1)) @ weights)
assert np.isclose(cam.mean(), score(features))
grad = central_gradient(score, features.astype(float))
alpha = grad.mean(axis=(0, 1))
assert np.allclose(alpha, weights / 4)
assert np.allclose(np.maximum(features @ alpha, 0), np.maximum(cam, 0) / 4)

13. Exercises with complete solutions

1. Why is a 99% pixel classifier potentially useless?

If positive pixels constitute 1% of the data, an all-background predictor is correct on 99% yet detects none of the defect pixels. Defect recall and nonempty-defect IoU are zero. Pixel accuracy weights every pixel equally, so background dominates. Evaluate foreground overlap, recall, object-level misses, and boundary errors according to the actual inspection action.

2. Prove max unpooling cannot generally invert pooling.

The patches \((1,4,2,3)\) and \((0,4,-1,2)\) have the same maximum, four, at the same location. Pooling plus an argmax index maps both to identical stored information. Any deterministic unpooling of that information produces the same output for both, so it cannot reconstruct both original patches. This is a direct many-to-one counterexample.

3. Compute a transposed-convolution output size.

Take input size five, stride two, padding one, dilation one, kernel three, output padding one. The formula gives \((5-1)2-2+2+1+1=10\). With output padding zero it gives nine. Neither size choice says that the operation inverts a preceding convolution; invertibility is a property of the map, not merely compatible dimensions.

4. Diagnose greedy object matching.

For the displayed cost matrix, greedy selection of cost one forces cost 100, totaling 101. The alternative pairing costs \(2+1.1=3.1\). This is not a numerical corner case: a locally attractive assignment can consume a prediction that another target needs. A global one-to-one objective is required when the loss is defined over unordered sets.

5. Separate a box score, overlap, and instance identity.

A score of 0.95 is a model output whose meaning depends on its training target and calibration. IoU of 0.4 is a geometric comparison with another box. Neither says whether two boxes refer to the same physical instance. NMS uses overlap and score as a heuristic to remove duplicates, so it can suppress nearby distinct objects or retain poorly overlapping duplicates.

6. Recover a score from CAM and identify what Grad-CAM drops.

The example map has total ten over four locations, so the bias-free score is 2.5. Grad-CAM in this special architecture returns \((1/4)\begin{bmatrix}0&1\\4&7\end{bmatrix}\). ReLU removes the negative contribution and the factor rescales the map, so averaging that displayed Grad-CAM map does not recover the original score. Visualization normalization can further change numerical scale.

14. Keep prediction and explanation as separate contracts

A useful inspection pipeline can need a category, a box, an instance mask, and a diagnostic map at once. Each requires its own target and verification. Spatial precision, assignment rules, and coordinate conventions are part of model behavior. The next lecture adds time: a moving scene introduces correspondence, temporal order, and evidence that cannot be read from an isolated frame.
