Numerical laboratory

These original experiments isolate mechanisms used throughout the book. Their values are hypothetical, not measured model performance. Change a parameter, predict the result, then inspect the calculation.

Temperature changes confidence without changing the winning score

Three fixed class scores are 0.78, 0.42, and 0.55. For temperature \(\tau\gt0\), \(p_i=\exp(s_i/\tau)/\sum_j\exp(s_j/\tau)\). Stable computation subtracts the largest scaled score before exponentiation.

A sharper distribution is not evidence of better calibration. The score ordering and predicted class are unchanged. Compare this experiment with chapters 2 and 16.

Prevalence determines the workload of a detector

Fix sensitivity at 90% and specificity at 95%. If prevalence is \(\pi\), expected precision is \(0.9\pi/[0.9\pi+0.05(1-\pi)]\). Counts below are expected values per 10,000 opportunities.

At 1% prevalence, most alerts are false even with these apparently strong conditional rates. Chapter 18 connects this arithmetic to the human response process.

Separate exact dynamics from numerical integration error

Chapter 14 derives a known Gaussian transport from noise \(\mathcal N(0,1)\) to data \(\mathcal N(2,0.25)\). Starting at noise value 1.25, the exact endpoint is 2.625. The slider changes only the number of Euler intervals; the velocity field remains exact.

The remaining discrepancy is integration error. A real generative model also has field-estimation error; more solver steps do not necessarily fix that source of error.

Reproduce the checks

numerical_lab.py contains deterministic NumPy checks for gradients, convolution, attention, overlap, distributed means, variational regularization, noising, and projection. Each chapter also contains an independently executed original Python example. verify_examples.py extracts and executes those actual examples and records mathematical delimiter, timestamp-heading, and provenance structure checks. Install the dependency listed in requirements.txt, then run:

python numerical_lab.py
python verify_examples.py

The interactive calculations run entirely in the browser with no network requests, persistent storage, uploaded data, or model downloads. Recorded numerical results and reader validation state exactly what was tested.
