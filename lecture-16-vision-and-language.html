Vision-language foundation models: alignment, grounding, and composition

A foundation model changes the unit of engineering. Instead of collecting a new labeled dataset and training a separate network for every task, pretraining creates an interface—text, points, masks, or tool calls—that can specify many tasks at inference time. The interface is also the failure boundary: contrastive similarity can ignore relations, fluent generation can lose spatial grounding, and a chain is only as reliable as its weakest tool and its composition logic.

Our running image contains a red mug inside a patch of grass beside a blue bowl. A user may ask for a zero-shot class, a caption, the mug's location, its mask, or whether the grass is inside the mug. Let the image encoder be \(f_I\), text encoder \(f_T\), image embedding \(v=f_I(x)/\|f_I(x)\|\), text embedding \(t=f_T(y)/\|f_T(y)\|\), and temperature \(\tau>0\). We will track what information each architecture keeps, discards, and passes to the next component.

Based on CS231N lecture 16 and its official slides: CLIP, CoCa, vision-language models, Molmo pointing, Segment Anything, and visual-program chaining. Derivations, the persistent mug case, numerical prompt ensemble, reliability calculation, and exercises are original teaching constructions. Dataset scale and benchmark results are attributed to primary papers; they do not imply universal generalization.

CLIP turns paired images and text into a shared retrieval geometry 5:20

Given a batch of \(N\) matched pairs \((x_i,y_i)\), define logits \(s_{ij}=v_i^\mathsf Tt_j/\tau\). The image-to-text loss is

\[ \mathcal L_{I\to T}=-\frac1N\sum_{i=1}^N\log\frac{\exp(s_{ii})}{\sum_{j=1}^N\exp(s_{ij})}, \]

and \(\mathcal L_{T\to I}\) reverses the softmax direction. CLIP averages the two. The diagonal pair is positive; the other batch members become negatives. Normalization makes the dot product cosine similarity, and \(\tau\) controls how sharply differences affect probabilities. A smaller \(\tau\) magnifies both useful separation and mislabeled or ambiguous pairs.

The primary CLIP paper uses this alignment to support linear probes, nearest-neighbor retrieval, and text-specified classification without teaching a closed category list. Scale matters because diversity supplies concepts and because large batches supply more negative comparisons. Scale does not prove that the representation encodes every relation needed downstream.

For the mug image, the pair “a red mug in grass” should be closer than “a blue bowl on a table.” But the bag of concepts mug, grass, and in can dominate without a robust binding between object and relation. “A mug in grass” and “grass in a mug” contain nearly identical words. A high global similarity can therefore coexist with failure on composition.

Zero-shot classification is text-prototype nearest neighbor 10:47

For classes \(c\in\{1,\ldots,C\}\), write prompts \(p(c)\), encode prototypes \(t_c\), and predict

\[ p(c\mid x)=\frac{\exp(v^\mathsf Tt_c/\tau)}{\sum_{k=1}^C\exp(v^\mathsf Tt_k/\tau)}. \]

This is a soft one-nearest-prototype classifier in the shared space. It uses no labeled examples from the target dataset, but “zero-shot” does not mean no relevant pretraining data. Internet image-text pairs may contain the concepts, styles, or even near-duplicates. Evaluation must distinguish absence of target labels from absence of related information.

Prompt wording changes the prototype because pretraining saw phrases in context, not isolated dataset identifiers. “A photo of a red mug” may align better than “red mug.” Prompt ensembling encodes several templates and averages normalized text features before renormalizing. It reduces sensitivity to one phrasing but can also average incompatible senses. The class description is part of the model.

from math import exp

def softmax(scores, temperature=0.5):
    z = [s / temperature for s in scores]
    m = max(z)
    e = [exp(a - m) for a in z]
    return [a / sum(e) for a in e]

# cosine scores for prompts: mug, bowl, grass
p = softmax([0.78, 0.42, 0.55])
assert p.index(max(p)) == 0
assert abs(sum(p) - 1.0) < 1e-12
assert softmax([0.78, 0.42, 0.55], 0.1)[0] > p[0]
print([round(x, 4) for x in p])

The subtraction of \(m\) is a numerically stable implementation of the same softmax. The last assertion checks the interpretation of temperature: reducing it sharpens the distribution without changing the top class. These numbers illustrate the classifier; they are not reported CLIP outputs.

CoCa adds generation so the representation must retain descriptive detail 18:24

Contrastive Captioners (CoCa) combines a CLIP-like global alignment loss with an autoregressive captioning loss. If caption tokens are \(y_{1:L}\), the generative term is

\[ \mathcal L_{\rm cap}=-\sum_{\ell=1}^{L}\log p_\theta(y_\ell\mid y_{<\ell},x), \qquad \mathcal L=\lambda_c\mathcal L_{\rm contrast}+\lambda_g\mathcal L_{\rm cap}, \]

with nonnegative weights \(\lambda_c,\lambda_g\). Global contrastive alignment supports efficient retrieval and classification. Token-level generation pressures visual features to preserve information needed to name attributes and relations. This is a multi-task inductive bias, not a proof that the decoder is grounded: a language prior can still generate plausible text unsupported by the image.

The persistent example shows the complementarity. A single embedding may separate mug images from bowl images. Generating “a red mug sits in grass beside a blue bowl” requires color, two objects, and spatial relations. Yet teacher-forced likelihood rewards predicting the reference caption; it cannot penalize every unsupported alternative that was not annotated.

CLIP-style models remain attractive because image and text embeddings can be indexed independently, making large-scale retrieval fast. An autoregressive decoder costs sequential generation and stores more detail. The right interface depends on whether the application needs ranking, description, or both.

Global alignment is open vocabulary but weakly grounded 20:15

Open vocabulary means a user can supply new text descriptions instead of selecting a fixed training label. It does not mean arbitrary concepts are understood. Performance depends on pretraining coverage, prompt meaning, visual domain, and whether the task can be expressed by global similarity.

Contrastive batches introduce another dependency. If two captions describe visually similar scenes, treating them as negatives can push semantically related examples apart. Hard negatives that differ only in relation—“mug in grass” versus “grass in mug”—can improve compositional sensitivity, but oversampling narrow hard cases can degrade broader representation quality. Data curation and batch construction define the supervision.

Image-level captions also omit locations. The final pooled or class token is explicitly trained for global contrast, while patch tokens may not receive direct grounding supervision. Intermediate features can retain useful spatial structure, but usefulness is empirical and layer dependent. Before attaching a detector or language model, probe which layer preserves object identity and coordinates.

Evaluation should include counterfactual pairs: swap subject and object, change a count, negate an attribute, or move one object while keeping the rest fixed. Ordinary retrieval benchmarks can be solved by recognizing nouns; minimal pairs test binding. For the mug case, require \(s(x,\text{“mug in grass”})>s(x,\text{“grass in mug”})\) by a margin, then repeat across paraphrases and domains.

A vision-language model maps spatial tokens into a language model 29:05

A common architecture freezes or initializes a vision encoder and a language model, then learns a bridge from visual features to the language token dimension. Let \(Z_I\in\mathbb R^{P\times d_I}\) be \(P\) patch features and \(W\in\mathbb R^{d_I\times d_L}\) a learned projection. The LLaVA paper develops this visual-instruction interface; schematically, \(Z_IW\in\mathbb R^{P\times d_L}\) enters the language sequence.

The global class token is insufficient for many questions because it compresses away which patch contains which object. The lecture notes that penultimate CLIP features often retain spatial information more useful for multimodal fusion than final patch features trained toward global representation. This is not architectural law: it must be checked for the encoder and objective used.

Flamingo uses a Perceiver Resampler to turn variable visual features into a fixed number of tokens and inserts gated cross-attention blocks into a pretrained language model. If language hidden states are \(H\) and visual tokens are \(Z\), a cross-attention update has the schematic form

\[ H' = H + \tanh(\alpha)\,\operatorname{Attn}(HW_Q,ZW_K,ZW_V), \]

where scalar or channelwise gate \(\alpha\) can initialize near zero, preserving pretrained language behavior at the start. Masking associates text with the preceding image in interleaved sequences. Training on many image-text episodes makes few-shot inference possible: demonstrations are context, not gradient updates.

For the mug, a user can show examples mapping images to structured descriptions, then request the same schema for a new image. The model inherits linguistic priors from the language model and visual evidence through cross-attention. If those sources conflict, fluent prior-driven completion can override weak or ambiguous pixels.

Pointing makes a model expose visual evidence 43:57

Molmo and its PixMo data extend text generation with pointing: outputs can include image coordinates that locate the evidence for an answer. A coordinate target can be normalized as \((\hat x,\hat y)=(x/W,y/H)\in[0,1]^2\), making it portable across resolution; downstream code maps it back to pixels. Multiple points can support counting, comparison, or reference to several objects.

Grounding changes observability. “The route number is 42” is hard to audit; a point on the bus display lets a verifier crop, run OCR, or ask a human. Pointing does not guarantee correctness. A model may point to the wrong region and generate a plausible answer, or point to relevant evidence but reason incorrectly. Evaluation must score answer accuracy, localization accuracy, and their joint consistency.

For the mug query, require a point inside the mug mask. If the answer says red while the point falls on blue bowl pixels, the pair is inconsistent even if each output separately looks plausible. This supports a verification chain: point, segment a local object, classify color within the mask, and compare to the generated answer.

Variable-resolution inputs also require coordinate discipline. If an image is resized with padding, a point in model coordinates must be inverted through both scale and offset. Treating normalized coordinates as if the crop filled the tensor can silently move evidence to the wrong object.

Segment Anything resolves prompts into several plausible masks 54:07

The Segment Anything Model separates a heavy image encoder, prompt encoder, and lightweight mask decoder. The image embedding can be computed once; points, boxes, or masks specify what the user means. This amortization makes interactive segmentation possible.

A point is ambiguous. Clicking the mug handle may mean the handle, the whole mug, or the mug-plus-handle assembly. SAM outputs multiple masks at different granularities with predicted mask-quality scores. During training, a minimum-loss or matching rule can avoid punishing every plausible interpretation when the annotation supplies only one. At inference, the user or downstream system chooses.

Let masks be \(M_k\) and ground truth \(G\). Intersection-over-union is \(\operatorname{IoU}(M_k,G)=|M_k\cap G|/|M_k\cup G|\). Selecting \(k^\star=\arg\max_k\operatorname{IoU}(M_k,G)\) is valid for training analysis because \(G\) is known. Deployment cannot use ground truth; it relies on predicted quality, extra prompts, or task-specific validation. Confusing these settings leaks labels into evaluation.

SAM's data engine alternated annotation, model training, model-assisted annotation, and automatic mask generation to scale mask collection. Model-in-the-loop labeling changes the dataset: later labels may inherit model proposal biases. Quality audits should stratify by collection stage and object regime.

Chaining composes specialized interfaces into new visual programs 1:00:12

A chain uses one model's output as another's input. Molmo can point to the mug, SAM can convert the point to a mask, a color classifier can inspect masked pixels, and a symbolic function can compare counts. VisProg generates programs that call a library of detectors, segmenters, depth estimators, or language models.

Composition makes intermediate state inspectable and reuses specialized models. It also compounds failure. If independent stages have correctness probabilities \(p_1,\ldots,p_K\) and every stage must succeed, end-to-end success is \(\prod_k p_k\). Three 95% stages yield \(0.95^3\approx0.857\), not 95%. Errors are rarely independent: domain shift can hurt every visual tool simultaneously.

Typed contracts reduce silent failure. A point tool should return coordinate system and confidence; a segmenter should return mask, quality, and image identity; counting should reject overlapping duplicate masks. Validate preconditions between calls. Cache deterministic features, parallelize independent tools, and route low-confidence outputs to a verifier rather than always extending the chain.

Tool creation is a further frontier. An agent may specify a missing capability, collect or synthesize data, train a new module, and add it to the library. This adds a second learning loop whose dataset, evaluation, and permissions must be audited before the generated tool controls a physical system.

Evaluation must follow the interface through to the task

No single benchmark certifies this stack. Retrieval needs recall at a fixed candidate pool and hard relational negatives. Zero-shot classification needs class-balanced accuracy, prompt sensitivity, and checks for pretraining overlap. Captioning needs reference metrics plus factuality audits because lexical similarity can reward fluent hallucination. Pointing needs distance or containment, segmentation needs region overlap and boundary quality, and a visual program needs exact end-to-end task success.

Use the mug scene to build a ladder. First ask whether the correct text ranks above a noun-matched counterfactual. Then classify the object under several prompts. Generate a caption and enumerate each claim. Require the mug point to fall inside an independently annotated mask. Select a SAM output without ground-truth leakage. Finally run the full chain and compare its answer with a direct model and a simple specialist baseline. The ladder localizes regression: if the chain fails while every component passes alone, the contract or composition is at fault.

Stress tests should alter one causal factor at a time: swap mug and bowl colors, reverse the spatial relation, add a second mug, blur an inscription, or resize with padding. Also measure abstention. A system that recognizes missing evidence and routes the case to a human can have lower nominal coverage yet higher utility than one that answers every prompt. Report latency and memory because a chain that loads several foundation models may be correct but unusable at the required interaction rate.

Exercises with worked solutions

1. Compute a two-class CLIP probability

An image has cosine similarities 0.8 and 0.5 to two class prompts, with \(\tau=0.1\). What is the first-class probability?

Solution. Subtracting the second logit, \(p_1=1/[1+\exp((0.5-0.8)/0.1)]=1/(1+e^{-3})\approx0.9526\).

2. Explain symmetric contrastive loss

Why include both image-to-text and text-to-image softmaxes?

Solution. The first makes each image select its paired text among batch texts; the second makes each text select its paired image among batch images. With duplicates or asymmetric ambiguity the conditionals differ, so averaging trains retrieval in both directions.

3. Diagnose a relational failure

The model scores “mug in grass” and “grass in mug” equally. Which successful benchmark result would fail to rule this out?

Solution. Ordinary category classification or retrieval dominated by object nouns can succeed while relation binding fails. Use subject-object swaps and other minimal-pair counterfactuals.

4. Map a padded point back to pixels

A \(640\times480\) image is scaled by 0.5 to \(320\times240\), then padded with 40 pixels on top in a \(320\times320\) tensor. The model returns tensor point \((160,160)\). Find the original point.

Solution. Remove padding: \((160,120)\). Divide by scale 0.5: \((320,240)\), the original image center.

5. Compute chain reliability

Pointing, segmentation, and OCR succeed independently with probabilities 0.9, 0.95, and 0.92. All are required. What is success probability?

Solution. Multiply: \(0.9\times0.95\times0.92=0.7866\). Independence is an assumption; shared image corruption can make joint reliability lower than this simple estimate suggests.

6. Prevent mask-selection leakage

A benchmark selects from SAM's three outputs using the highest IoU with ground truth, then reports that IoU as deployment performance. What is wrong?

Solution. Ground truth chose the output, so the evaluation grants information unavailable at deployment. Select by the model's predicted quality or a prespecified interaction policy, then score that selected mask.

What this chapter establishes

CLIP learns a shared retrieval geometry; text prototypes turn it into a zero-shot classifier; CoCa adds descriptive generation; vision-language models preserve patch information and fuse it into language; pointing exposes evidence; SAM maps prompts to ambiguous masks; and chaining composes these interfaces. Each step expands capability by retaining or exposing information the previous interface compressed away. The price is new dependence on prompts, grounding data, coordinate transforms, component calibration, and end-to-end verification.
